<h1 style="color: blue;"> Purpose of the Server </h1>

The first version of the Minecraft server was just a simple vanilla survival Minecraft server. The entire server was and still is being hosted by a third party. However, over the years, we added in different sub-servers with different gamemodes. The gamemodes were added not so long after COVID-19 happened. The survival server is still active.

<h1 style="color: blue;"> Contents of the Server </h1>

For one of the gamemodes, I made a simple Minecraft datapack that was used in a hide and seek gamemode.
