<h1 style="color: blue;"> The Task </h1>

In high school, in order to recieve a CTE Honors we had been tasked with a Performance-Based Assessment (PBA) assignment to complete from the start of the last quarter to the end of the quarter. In order to complete the assignment, we had to work in a group of 3 or less. Me and my two other friends teamed up to complete this assignment. Since our knowledge of Java was only basic, we had to self-learn some of the libraries we could utilize for this password manager.

<h1 style="color: blue;"> The Password Manager </h1>

The password manager we created had three options. Generate a new password, store an already existing password, and view all the passwords you have. For the password generator portion, instead of using .random(), which generates only just a pseudo random number, we seeded every random character randomly. This makes it harder to predict. The password manager had "encryption key" that was stored inside of a .txt file. The .txt file itself was supposed to be a "proof of concept" rather than a permanent storage for the passwords/keys.

<h1 style="color: blue;"> Key Takeaways </h1>

Since we were required to work on a team, it was hard to communicate some ideas. However, at the end, I learned how to communicate with my team members such as bringing up new ideas on how to solve a problem or solving a bug in the code. One of the bugs that happened was that we were comparing strings to integers rather than integers to integers, so the whole code fell apart. We were successful in every debugging process.
