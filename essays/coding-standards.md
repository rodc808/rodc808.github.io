<h2 style="color: blue;">The Value of Coding Standards</h2>
<p>Coding standards are normally thought of as proper indentation or placements of brackets. However, coding standards are more than that. These coding standards help developers build good habits and adbot a consistent coding style that makes their code easier to understand for everyone. When everyone writes code the same way, reviewers spend their time on the logic and not the style. Developing these good habits prevents bugs by catching bugs before the code ever runs since it's easy to read.</p>  
<p>Other than the previously mentioned formatting, there's also naming conventions and anti-pattern avoidance. In this way, coding standards can be viewed as the grammar and style of a programming language.</p>
<p>We were introduced to ESLint as a requirement for this class. Initially, I thought it was another formatting extension but I realized that it was more powerful. To me, ESLint became a helpful tool for writing better code because it identified certain variables that were declared but not used. Knowing these variables and their usage in the code is helpful because you would know if something isn't working.</p>

<h2 style="color: blue;">Applying ESLint and Reflecting</h2>
<p>For example, in one of our WOD's we had to work with a file containing the lyrics of Justin Bieber's "Baby." Although I was referencing the array from another file, ESLint flagged it as "defined but never used." To resolve this issue, I added a console.log statement to print the length of the array. ESLint allowed me to follow coding standards more effectively in developing and maintaining code.</p>
<p>Using ESLint helped me understand how important coding standards in developing programs and how tools such as ESLint can support purpose by reducing bugs, maintaining readability and consistency.</p>
