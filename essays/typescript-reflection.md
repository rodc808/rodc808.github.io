<h1 style="color: blue;"> Knowledge Prior to Learning Typescript </h1>

Prior to learning Typescript, the only languages I've known was Python, C#, and most importantly, Java. I became the most comfortable with Java throughout my entire coding journey. It probably has to do with the fact that I've spent more time with Java since it was the first coding language I've learned since I was in middle school. Another factor could be that the logic in Java is more friendly to read rather than Python's strict indentation rules and hard to read syntax structure.

<h1 style="color: blue;"> First Impressions </h1>

The first thing that came into mind was that Typescript was uncannily similar to Java. I'm pretty sure it has to do with the fact that their syntaxes are almost identical. The only thing I found a little challenging was setting the types of the variables. In Java, it's pretty straightforward. You declare the type you want your variable to be, then make it - like a prefix in a word. In Typescript, it's completely flipped. You declare your variable then make it whatever type you want it to be - like a postfix in a word. One thing I found pretty nice with Typescript was that you could just declare a new object without having to create a class. It saves time sometimes when creating some programs while I was doing my WODs (Workout Of the Day) for my ICS 314 Software Engineering class at UH Manoa. Of course a class would help a lot to keeping it organized but if I wanted to just do so I can. In the real world, however, I'm not so sure how this could be used. I mean, I haven't had that much experience with Typescript as of now but I'm almost confident that in the future I'll be able to utilize this special feature of Typescript to my advantage. I'll write about my Typescript journey more. It's a very interesting language.

<h1 style="color: blue;"> Expanding on Classwork </h1>

Currently, I'm 3 weeks into my ICS 314 journey. I wasn't too fond of it at the start since there was an immediate workload on day 1. It probably also has to do with the fact that I'm also currently taking ICS 311, algorithms, which as of now is definitely the hardest class I have ever taken. However, once I started laying out my schedule I found ICS 314 to be manageable. The course runs a flipped/reversed classroom style format. The point of a flipped classroom is that you do activities during class time and learn all the course content outside of class. They provide you with the lessons and directions on a separate website the ICS 314 instructors made for the class specifically. I find the format of the teaching style to be neutral. On one side, I really enjoy it because you can do the course in your own time. On the other side, however, I'd prefer at least some lectures to be about Typescript to help students (or well, really me) clarify what some parts of it is.

<h1 style="color: blue;"> Conclusion </h1>

Overall, the way how I was introduced to Typescript was an interesting one. As a person who touched almost all the "main" coding languages, I find it really enjoyable to learn. Even if it's essentially self learning, the ICS 314 class I'm taking and their required WODs help reinforce my learning.
