## Knowledge Prior to Learning Typescript

Prior to learning Typescript, the only languages I've known was Python, C#, and most importantly, Java. I became the most comfortable with Java throughout my entire coding journey. It probably has to do with the fact that I've spent more time with Java since it was the first coding language I've learned since I was in middle school. Another factor could be that the logic in Java is more friendly to read rather than Python's strict indentation rules and hard to read syntax structure.

## First Impressions

The first thing that came into mind was that Typescript was uncannily similar to Java. I'm pretty sure it has to do with the fact that their syntaxes are almost identical. The only thing I found a little challenging was setting the types of the variables. In Java, it's pretty straightforward. You declare the type you want your variable to be, then make it - like a prefix in a word. In Typescript, it's completely flipped. You declare your variable then make it whatever type you want it to be - like a postfix in a word. One thing I found pretty nice with Typescript was that you could just declare a new object without having to create a class. It saves time sometimes when creating some programs while I was doing my WODs (Workout Of the Day) for my ICS 314 Software Engineering class at UH Manoa. Of course a class would help a lot to keeping it organized but if I wanted to just do so I can. In the real world, however, I'm not so sure how this could be used. I mean, I haven't had that much experience with Typescript as of now but I'm almost confident that in the future I'll be able to utilize this special feature of Typescript to my advantage.
